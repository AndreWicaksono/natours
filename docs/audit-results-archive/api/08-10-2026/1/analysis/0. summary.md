### 🟢 6 Best-Practice Gaps

- **BP-1**: `console.log`/`console.error` in webhook controller — use NestJS `Logger`
- **BP-2**: `billing.stripe_webhook_events` table exists in schema but is **never used** — Stripe can replay events and create duplicate `PlatformTransfer` records
- **BP-3**: Stale `import { JwtAuthGuard }` in 3 controller files after the Oct 4 cleanup
- **BP-4**: `test-expire` `@Public()` endpoint has no `NODE_ENV` guard
- **BP-5**: `PartnersController` returns `{ error: '...' }` with 200 instead of throwing `NotFoundException`
- **BP-6**: Code reads `SITE_URL` env var, README documents `APP_URL` — Stripe redirect URLs will be `undefined` in any env that only sets `APP_URL`
